# Social Media, Screen Time & Mental Health Analysis

## Project Overview
This Power BI project explores patterns between social media usage, screen time, sleep duration, and mental health indicators. The goal is to analyse the data, identify meaningful patterns, and present insights through interactive dashboards.

## Objectives
- Analyse screen time and social media usage patterns.
- Explore the relationship between screen time and sleep duration.
- Examine patterns in mental health and wellbeing indicators.
- Build interactive dashboards to support data exploration.
- Provide recommendations based on the observed patterns.

## Tools & Technologies
- **Power BI** – Data visualization and interactive dashboards
- **Power Query** – Data preparation and cleaning
- **DAX** – Calculated columns and measures
- **Kaggle** – Dataset source

## Data Preparation
The dataset was prepared before creating the dashboards. The work included:
- Reviewing column names and data types.
- Checking missing values.
- Handling missing values in Average Sleep Hours using the median.
- Preparing the data for analysis and visualization.

## Key Findings
The dashboards help explore patterns between screen time, sleep duration, and wellbeing indicators. Interactive slicers allow users to filter the data and compare different groups.

**Note:** The findings represent patterns and associations in the dataset. They do not establish that screen time or sleep directly causes a particular mental health outcome.

## Recommendations
- Encourage awareness of screen-time habits.
- Promote healthy and consistent sleep routines.
- Use the dashboard filters to explore differences between groups.
- Interpret mental health indicators carefully and avoid drawing conclusions beyond the available data.
